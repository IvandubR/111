# NodeSpecter

Minimal landing page for NodeSpecter project.

**Features:**
- Dark theme
- Social links (Twitter, Telegram, GitHub)
- Responsive design
- Base64 embedded logo

**Usage:**
1. Open `index.html` in your browser.
2. Customize content, logo, or links as needed.
3. Deploy to GitHub Pages or any web server.

**Tech Stack:** HTML, CSS
